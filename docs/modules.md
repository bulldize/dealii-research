# 公共模块与验证状态

本仓库是独立于 deal.II 源码的 C++ 科研库。首版覆盖二维、单位正方形、齐次速度边界、连续三角形有限元；它是完成首个实际算例的基础库，不宣称已经实现所有未来论文需要的能力。

| 模块 | 文件/符号 | 可复用部分 | 当前证据 |
|---|---|---|---|
| 场与参数 | `fields.h`: `Field`, `Parameters` | 速度、压力、完整 2×2 张量的分量约定和梯度 | 通过装配和制造解检查 |
| Giesekus 本构 | `giesekus.h`: `Giesekus` | 应力、三次松弛项及解析方向导数 | 随机方向导数、耦合抵消测试 |
| 耦合弱形式 | `forms.h`: `transport`, `residual`, `jacobian` | 不可压流体、反对称输运、后向差分、张量扩散；本构由模板参数选择 | 完整 Jacobian 与有限差分比对、局部能量抵消 |
| 有限元运行层 | `solver.cc`, `solver.h`: `Problem`, `run` | 三角网格、P2/P1/P1 元、约束、L2 投影、装配、Newton、UMFPACK、诊断、VTU | 单次完整制造解实验，弱散度与全局能量恒等式检查 |
| 算例 | `manufactured.h`: `exact`, `source` | 论文 5.2 节的解与连续方程源项 | 独立数值微分核对源项 |
| 程序入口 | `apps/giesekus.cc` | 参数解析与 `Problem` 回调组合 | 实际配置完整运行 |
| 实验记录 | `scripts/analyze.py` | 读取原始历史、检查完成状态、生成图与验收记录 | 对最终输出执行 |

修改模型时先复用场、输运和时间项。弱形式模板接受相同应力/松弛/导数接口的其他本构，但当前 `run` 编译使用 Giesekus，替换模型还须适配运行层的能量诊断并重新验证。并非任意模型都自动继承这篇论文的能量结构。

修改制造解或源项可通过 `Problem` 回调进行，无需重写网格或装配。已扩展 4:1 收缩流的非齐次入口、F 入口及出口边界积分，并完成小网格运行；其他几何仍需适配并验证。

验证状态为“自动化数学检查通过＋单配置数值实验完成”，尚未经用户人工审阅。后续记录复用、适配和新增部分；保持未受影响的已验证模块稳定。MPI、预条件迭代、全线性格式、离散链式法则输运目前未实现。收缩流全尺寸结果及 66 个配置的科学结论尚待验证。

`assembly.h` 提供分量稀疏化的解析 Jacobian，已与通用弱形式导数逐项比较。`run_suite.py` 保存输入和二进制指纹并并行执行独立算例；`calibrate_server.py` 在最大网格上测量峰值内存和 1/2/4 线程吞吐量，选择并发配置。这些调度选择不修改论文参数。
