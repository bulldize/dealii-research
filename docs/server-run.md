## 独立运行

依赖完成后，在服务器仓库运行：

```sh
mkdir -p results/full-paper
nohup bash scripts/server_pipeline.sh > results/full-paper/pipeline.log 2>&1 < /dev/null &
```

工作流依次执行构建、数学检查、小算例、最大网格性能测量、两组正式队列、绘图及完整性报告。`flock` 防止重复启动。断开 SSH 后继续运行，但 Windows 休眠、WSL 关闭或重启会中断任务。

查看 `results/full-paper/phase.txt` 和 `pipeline.log`；性能测量在 `calibration/measurements.json` 与 `settings.json`。每个算例保存配置、源码/程序/网格指纹、线程环境、日志、时间历史和最终场。最终报告为 `REPORT.md`、`audit.json`。

单个算例失败会留痕并继续其他算例。已完成且指纹匹配的算例可跳过；未完成目录不会覆盖，需保留后换输出目录重跑。目前没有时间步断点续算，不应宣称重启可自动续算。
